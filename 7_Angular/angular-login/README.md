# Angular 21 - Login com validação e captcha

Projeto exemplo com:

- Tela de login com usuário e senha (admin/admin)
- Validação de formulário reativo
- Captcha matemático simples
- Redirecionamento para dashboard geral após autenticação
- Estrutura padrão com header, body e footer

## Executar

```bash
npm install
npm start
```

Acesse: `http://localhost:4200`
